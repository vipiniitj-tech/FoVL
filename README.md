# FoVL – Multilingual Word Embedding Learning

## Overview

FoVL is a project focused on learning multilingual word embeddings using the **FastText Skip-gram** model.

The project explores how word representations can be learned from text data so that words with similar meanings or linguistic contexts have meaningful vector representations.

## Objectives

- Learn word embeddings using the FastText Skip-gram architecture.
- Explore multilingual word representation learning.
- Understand the application of FastText in natural language processing (NLP).
- Train and experiment with word embedding models using Python.

## Methodology

The project uses the **FastText Skip-gram** approach.

FastText extends traditional Word2Vec by representing words using character-level n-grams. This helps the model learn representations for rare words and words that were not encountered during training.

The Skip-gram architecture learns to predict surrounding context words from a given target word.
